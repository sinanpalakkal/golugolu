🚀 Why Golugolu?

Golugolu is a fun experimental search engine created as a personal project.


The idea is simple: What if a search engine didn't take searching seriously?


Built using Python and Django, Golugolu combines programming, creativity and a little bit of humour to create an unusual searching experience.


It might not always give you useful answers, but at least it won't let you search in peace! 😂
